# Code of Conduct

CursRO follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep discussions about the project. Harassment, insults and personal attacks are not tolerated.

To report unacceptable behaviour, contact the maintainer privately through their GitHub profile. Reports are handled confidentially.
