API gratuit

Fișiere statice, fără cheie și fără limită de cereri. Se actualizează în fiecare zi lucrătoare, după ce BNR publică cursul.

    const res = await fetch("https://robert-georgedev.github.io/CursRO/data/latest.json");
const { date, rates } = await res.json();
console.log(`1 EUR = ${rates.EUR} lei (${date})`);

    Sursa datelor: Banca Națională a României. CursRO nu este afiliat BNR; pentru valori oficiale, verifică bnr.ro.
